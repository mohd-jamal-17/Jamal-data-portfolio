# Project 3: Clinical Hospital Data Analysis 🏥📊

This project showcases data analysis of hospital performance using:
- ✅ SQL for data extraction
- ✅ Excel for cleaning
- ✅ SAS for transformation
- ✅ Tableau for visualization
