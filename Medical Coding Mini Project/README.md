# 🏥 Medical Coding Mini Project

This mini project is a practical introduction to **Medical Coding** using **ICD-10**, **CPT**, and **HCPCS** standards.  
It covers symptom analysis, diagnosis identification, test/procedure coding, and medication/supply coding.

---

## ✅ What You’ll Learn
- ICD-10 Diagnosis Coding  
- CPT Procedure Coding  
- HCPCS Supply/Drug Coding  
- How to read a case and assign the correct codes

---

## 📂 Files Included

| File | Description |
|------|-------------|
| `Cases.md` | Real-world sample cases with proper medical codes |

---

## 🛠️ Tools Used
- No software needed, just logic and official codebooks
- Verified codes using **ICD-10**, **AMA CPT**, and **CMS HCPCS** references
